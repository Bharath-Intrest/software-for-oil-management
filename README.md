# Software for oil management

A lightweight, efficient desktop application designed to automate stock tracking, manage sales and forecast inventory needs for a retail oil business. Built with Python and Tkinter, this system replaces manual ledgers with a streamlined digital workflow.

## Key Features

* Main feature is that the app will track different oil types and quantities (in litres).
* Uses Threads to enable multiprocessing which saves lots of time rather than waiting for a SQL query to complete
* Securely stores and retrieves inventory and transaction data using SQL.

## Tech Stack

* **Language:** Python 3.x
* **GUI Framework:** Tkinter
* **Database/Storage:** SQL
